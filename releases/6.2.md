# GEMC Release 6.2

Upcoming in the next release. Changes since `6.1`.

This version includes:

- Optimized LTCC CAD geometry with restored walls and nose hardware.
- Updated ALERT AHDC digitization with wire-dependent time-to-distance calibration.
- Added DDVCS 15-degree calorimeter and high-luminosity beamline configurations.
- Disabled FT readout in configurations where the detector is off.
- Enabled command-line execution of multiple Geant4 macros.

<br/>

# Release notes

- Optimized LTCC CAD meshes, restored the walls and nose hardware, and fitted the sector mother volumes.
- Updated ALERT AHDC drift-time digitization to use the new wire-dependent time-to-distance function and
  its inverse.
- Fixed `EXEC_MACRO` handling so command-line macros are executed in both GUI and batch modes, including
  multiple macro arguments.
- Corrected MuCAL geometry generation to create only volumes supplied by the Coatjava factory and use
  the standard detector-generation entry point.
- Disabled FT calorimeter and hodoscope sensitivity for FT-off configurations while retaining their
  passive material.
- Added the DDVCS `15deg` variation with matching calorimeter acceptance and shielding, and moved the
  DDVCS Moller cone into the beamline system.
- Added the `elmo7` high-luminosity beamline variation with a tungsten cone and matching vacuum pipe.
- Made geometry generation report missing prerequisites, detector directories, and detector scripts as
  errors, and ensured build jobs propagate geometry-generation failures through logging pipelines.

<br/>

- Documented the upcoming LTCC CAD layout, retained engineering drawings, benchmark procedure, and

## Tests

- Added an offline LTCC CAD benchmark separating loading, electron and hadron transport, and overlap
  diagnostics.
- Limited scheduled ASCII/SQLite comparisons to detectors affected by commits in the last 24 hours;
  manual runs, shared-code changes, and unavailable history retain the full comparison matrix.
- Made ASCII/SQLite comparison summaries fail the workflow when geometry or digitization checks fail,
  while allowing unchanged detectors to be skipped.
- Added Java 21 and Git LFS setup to CodeQL builds and prepared Coatjava before ASCII/SQLite comparisons.
- Migrated Valgrind profiling to the Callgrinder action with per-workload artifacts, aggregated category
  reports, and QCachegrind guidance. Profiles now run GEMC directly after module setup.
- Added run `4763` to the CI lookup for the `rga_fall2018` variation while retaining run `4760`.

## Compatibility notes

- Custom beamline CAD placements must use `moller_cone` in place of `main-cone`.

- Use `FTInnerShield` in place of `taggerInnerShield` in custom beamline CAD placements.

- The beamline outer mount now uses `FTOuterMount`; custom CAD placements
  using `outerMount` must use the new name to match the STL.

- The beamline outer flange now uses `FTOuterFlange`; custom CAD placements
  using `outerFlange` must use the new name to match the STL.

- The nine beamline fasteners now use `FTInnerShieldAndFlange_Bolt1` through `Bolt9`; custom CAD
  placements using `nut1` through `nut9` must use the corresponding new mesh names.

- The beamline inner shield and flange now use `FTInnerShieldAndFlange`; custom CAD placements
  using `innerShieldAndFlange` must use the new name to match the STL.

- The three beamline adjuster volumes are replaced by `ft_adjuster`; custom CAD placements must
  replace the trio with one row retaining their common material, position, and rotation.

- The beamline CAD reducer is now `Beamline_Adapter_1`; custom GXML placements using
  `Torus_Beam_Tube_Reducer_2` must use the new name to match the renamed STL.

- The beamline CAD hub is now `Apex_Shield_Hub`; custom GXML placements using
  `Apex_Shield_PCAL_Hub` must use the new name to match the renamed STL.

- ALERT AHDC digitization now reads `/calibration/alert/ahdc/time_to_distance_wire` with ten coefficients
  per wire instead of the former global six-coefficient `time_to_distance` table.
- FT readout is disabled for `rgk_winter2018`, `rgf_spring2020`, `rgd_fall2023`, and `rgc_summer2022`.
- Custom DDVCS gcards must load the beamline `ddvcs` variation to include the Moller cone.
- Direct MuCAL generation now uses `mucal.pl` instead of `init_muCal.pl`.

## Detailed list of changes and fixes
- Synchronized the three cured HTCC cone meshes with GEMC3, reducing their total triangle count from
  26,798 to 13,614 and closing the entry cone's 144 boundary edges; archived the original inputs and
  retained all run-dependent placements. Documented the Moller cone's remaining non-manifold edges
  and the imported entry cone's residual 0.053 mm contact with the entry window.

- Cleared FT and Moller cone CAD interface overlaps with local reliefs in five meshes, retaining the
  shield, flange, tip, placements, and materials; recorded geometry checks and tracking benchmarks.

- Renamed the Moller-cone extension tungsten add-on in four runs and restored its missing radial-port
  wall without capping the passages, and reduced it to 12,000 triangles with protected features.
  Recorded separate raw-input and closed-reference tracking benchmarks and retained assembly warnings.

- Renamed and optimized the Moller cone extension lead fill and casing in four run configurations,
  preserving inner interfaces and openings; recorded repeated tracking measurements and assembly checks.

- Renamed the inner Moller-cone extension in four run configurations, restored its missing radial-port
  wall without capping the passages, and reduced it to 12,500 triangles with protected features.
  Recorded separate raw-input and closed-reference tracking benchmarks and retained assembly warnings.

- Renamed the beamline flange assembly to `FTFlange` in four run configurations and reduced its
  already-coarse mesh from 552 to 540 triangles with retained opening, face planes, and bounds.
  Repeated tracking measurements show no meaningful gain; existing assembly defects remain.

- Renamed the Moller cone tip in four run configurations and reduced its mesh to 5,000 triangles,
  retaining sharp faces, openings, bounds, and tungsten volume within 0.0005%; recorded isolated
  tracking speedups and the pre-existing cone/tip overlap separately.

- Relieved both downstream Segment 1 sockets to clear the adapter and Segment 2 while preserving
  placements and neighboring meshes; verified clean assembly and full default construction.
- Recorded the downstream socket material change and repeated three-part tracking comparison.

- Renamed and optimized the Moller cone to 5,000 triangles, filled its surface holes, and widened
  its entrance counterbore to clear the unchanged FT inner shield in every placement.
- Recorded independent cone/shield clearance, material changes, and repeated raw-input and
  repaired-reference tracking comparisons in the CAD optimization note.

- Rebuilt and simplified the renamed FT inner shield to 6,500 triangles with smooth flange faces
  and all flange/tube holes filled; retained its longitudinal grooves and recorded material changes.

- Reduced the renamed FT outer mount to 2,740 triangles while retaining its engineering
  openings, material, and placement; repaired four missing faces and relieved the flange joint.

- Reduced the renamed FT outer flange to 836 triangles while retaining its engineering
  rims, central opening, material, and placement; closed twelve bolt holes and archived the original.

- Simplified nine renamed FT inner-shield bolts to 192 triangles each, retaining copper volumes
  within 0.0001%, preserving placements, and leaving 0.15 mm at the shield blind-hole end faces.

- Reduced the renamed FT inner shield and flange to 22,000 triangles while retaining its enclosed
  pocket, bounds, topology, alloy material, and placement; archived the engineering mesh.

- Unified the FT adjusters into one 48-triangle material model matched to the sealed reference
  union volume, with archived originals and synchronized placements and database rows.

- Renamed the beamline reducer to `Beamline_Adapter_1` across CAD placements and database rows;
  conservatively reduced adapter and exit-casing triangulations while preserving casing mating faces
  and retaining the coarse lead fill exactly.

- Repaired the downstream beam tube's missing annular joins and registered their angular grids without
  capping the bore; reduced the two tube meshes to 5,000 and 600 triangles and archived the originals.

- Optimized the beamline apex lead fill and hub while preserving topology, materials, and placements;
  reduced their triangle counts to 1,440 and 20,000 and archived the original engineering meshes.

- Built inverse AHDC calibration tables for all 576 wires using the new three-line time-to-distance
  function with smooth transitions, cubic interpolation, and linear interpolation near table boundaries.
- Removed unused MuCAL panel builders, legacy material definitions, and obsolete parameter files;
  corrected its configuration to point to the local SQLite database.
- Recomputed DDVCS calorimeter mother dimensions from the angular cut and applied the same cut when
  selecting crystals, supporting both the existing 30-degree and new 15-degree configurations.
- Resolved geometry-generation paths relative to the script and exposed the repository's Perl API through
  `PERL5LIB`, with early checks for DBI, DBD::SQLite, and XML::LibXML.
- Updated the reported GEMC version to `6.2`.
- Replaced the LTCC frame with shared wall and nose CAD sources inside sector mothers, introduced the
  effective nose material, and removed obsolete frame-volume production cuts from the gcards.
- Retained the original LTCC engineering meshes separately from the optimized active CAD assets.
