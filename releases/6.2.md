# GEMC Release 6.2

This version includes:

- Added the MUCAL geometry, imported from coatjava and displayed in GEMC.
- Updated the ALERT AHDC digitization for the new time-to-distance (T2D) function.
- Applied `EXEC_MACRO` to the command line as well as the steering card.
- Disabled forward tagger (FT) sensitivity in the OFF configuration.

Based on [Coatjava Release](https://github.com/JeffersonLab/coatjava/releases) 14.1.2.

<br/>

# Release notes

- Added the MUCAL geometry, imported from coatjava and displayed in GEMC, with an algorithm fix and generation
  of the real panels only.
- Updated the ALERT AHDC hit process to use the new time-to-distance (T2D) function.
- Applied `EXEC_MACRO` to the command line in addition to the steering card.
- Disabled forward tagger (FT) sensitivity when the FT is in the OFF configuration.

<br/>

## Tests

- Fixed the ascii-versus-SQLite comparison workflow and added Git LFS to it.
- Fixed the Java version and installed Git LFS in the CodeQL workflow.
- Hardened geometry creation so a failed creation no longer produces a false comparison-miss failure.
- Removed the masking of commands after pipes in the build scripts.

<br/>

## Detailed list of changes and fixes

- Imported the MUCAL geometry from coatjava through `geometry_java.pl`, added its configuration, applied the
  MUCAL algorithm fix, and restricted generation to the real panels only.
- Renamed `init_muCal.pl` to `mucal.pl` and cleaned up the MUCAL materials handling, removing the obsolete
  `materials.pl` references.
- Reworked the ALERT AHDC hit process header and implementation for the new T2D function.
- Extended `EXEC_MACRO` handling in `gemc.cc` so macros passed on the command line are also executed.
- Reworked the FT geometry so sensitivity is disabled when the detector is in the OFF configuration.
- Hardened `create_geometry.sh` and `ci/build_gemc.sh` against geometry-creation failures.
- Added Git LFS installation and fixed the Java version in the CodeQL and ascii-versus-SQLite comparison
  workflows.
