# GEMC Release 6.2

Upcoming in the next release. Changes since `6.1`.

This version includes:

- Optimized LTCC CAD geometry with restored walls and nose hardware.
- Updated ALERT AHDC digitization with wire-dependent time-to-distance calibration.
- Added DDVCS 15-degree calorimeter and high-luminosity beamline configurations.
- Disabled FT readout in configurations where the detector is off.
- Enabled command-line execution of multiple Geant4 macros.

<br/>

# Release notes

- Optimized LTCC CAD meshes, restored the walls and nose hardware, and fitted the sector mother volumes.
- Updated ALERT AHDC drift-time digitization to use the new wire-dependent time-to-distance function and
  its inverse.
- Fixed `EXEC_MACRO` handling so command-line macros are executed in both GUI and batch modes, including
  multiple macro arguments.
- Corrected MuCAL geometry generation to create only volumes supplied by the Coatjava factory and use
  the standard detector-generation entry point.
- Disabled FT calorimeter and hodoscope sensitivity for FT-off configurations while retaining their
  passive material.
- Added the DDVCS `15deg` variation with matching calorimeter acceptance and shielding, and moved the
  DDVCS Moller cone into the beamline system.
- Added the `elmo7` high-luminosity beamline variation with a tungsten cone and matching vacuum pipe.
- Made geometry generation report missing prerequisites, detector directories, and detector scripts as
  errors, and ensured build jobs propagate geometry-generation failures through logging pipelines.

<br/>

## Compatibility notes

- The native `solenoid` bank is now `magnets`; its physical volume name is unchanged. Magnet copies
  join native `magnets`, and DC copies join native `dc`. Retire separate copy-bank card entries and
  regenerate SQLite/TEXT geometry; CAD source factories remain `magnets_cad` and `dc_cad`.

- Renamed `CenterTube` to `BoreCenterTube` in all three CAD configurations. The three bore meshes
  retain all 1,130 facets, profiles, and holes; no simulation speedup is established for this step.

- Renamed Hub001 to ColdHub, retaining every hole while repairing the export seam, face winding, and
  degenerate junctions. The closed genus-34 mesh has no self-intersections and uses 12,548 instead of 12,600
  facets. Magnets now has 66,960 unique facets in 20 STL sources and 39 placements; supplied cards need no
  changes.

- Renamed the seven Shield volumes with the hub_shield prefix and shared the five matching middle pieces while
  retaining both different end profiles and every hole. Unique facets fall from 4,146 to 1,594; magnets now
  uses 20 CAD sources and 19 native copy rows per run. Nanometre axial normalization prevents new contacts
  from STL rounding at stepped joints.

- Renamed Plate1 through Plate6 to hubCover1 through hubCover6 and shared two unchanged meshes across the
  plain and holed groups, retaining every hole. Unique facets fall from 348 to 162; this step used 24 CAD
  sources and 15 native copy rows per run.

- Shared the six torus coils through one unchanged `coil` STL and five native copies, retaining all openings;
  unique facets fall from 6,096 to 1,016; this step used 28 CAD sources and 11 native copy rows per run.

- Renamed all shell placements to `vacuumJacket` with sector/side suffixes and added six copy placements using
  native `magnets_copies` rows. Load that bank with magnets CAD, as in the supplied cards. The a/b jackets
  remain distinct and all holes remain; four original meshes preserve contact coordinates or extra
  components. Jacket unique facets fall from 93,726 to 47,934; existing assembly overlaps remain.

- Moved six region-1 aluminum supports from magnets to DC: one unchanged STL and five native copies
  reduce 6,036 unique facets to 1,006. Openings and both pieces remain; integer-angle placements pass
  dense assembled overlap checks, with a maximum 2.76 mm displacement from the engineering placements.

- Moved the six region-1 DC back membranes from magnets to DC CAD, sharing one 20-triangle mesh
  through five native `CopyOf` placements. Load `dc_cad` with `dc_copies` for SQLite, or CAD with
  the TEXT copy bank. Supplied DC cards include both. Original names and sector offsets remain;
  integer angles pass dense assembled overlap checks and shift vertices by at most 0.76 mm.
  Sharing the rounded thin-film reference adds about 0.5% total signed Kapton volume.

- The separate `UpstreamShieldingPlate` and `UpstreamVacuumJacket` retain their names and placements,
  with fourteen fastener features filled and 4,256 triangles reduced to 1,512. Signed material
  volume increases; original apertures, stepped bore, outer rounded features, and axial gap remain.

- The optimized `DownstreamShieldingPlate` and `DownstreamVacuumJacket` meshes retain their original
  names and separate placements. Filling eight through-holes and six blind bolt recesses reduces
  their total from 3,772 to 1,064 triangles while retaining their main apertures, rim coordinates,
  bounds, and axial gap. Signed material volume increases by 0.56658%; originals are archived.

- Load the beamline alongside magnets for downstream and apex shielding. All three magnets CAD
  configurations remove the nine `DSShield*` placements and `apex`. Regenerate the SQLite database to
  remove stale CAD rows.

- Custom beamline CAD placements must use `moller_cone` in place of `main-cone`.

- Use `FTInnerShield` in place of `taggerInnerShield` in custom beamline CAD placements.

- The beamline outer mount now uses `FTOuterMount`; custom CAD placements
  using `outerMount` must use the new name to match the STL.

- The beamline outer flange now uses `FTOuterFlange`; custom CAD placements
  using `outerFlange` must use the new name to match the STL.

- The nine beamline fasteners now use `FTInnerShieldAndFlange_Bolt1` through `Bolt9`; custom CAD
  placements using `nut1` through `nut9` must use the corresponding new mesh names.

- The beamline inner shield and flange now use `FTInnerShieldAndFlange`; custom CAD placements
  using `innerShieldAndFlange` must use the new name to match the STL.

- The three beamline adjuster volumes are replaced by `ft_adjuster`; custom CAD placements must
  replace the trio with one row retaining their common material, position, and rotation.

- The beamline CAD reducer is now `Beamline_Adapter_1`; custom GXML placements using
  `Torus_Beam_Tube_Reducer_2` must use the new name to match the renamed STL.

- The beamline CAD hub is now `Apex_Shield_Hub`; custom GXML placements using
  `Apex_Shield_PCAL_Hub` must use the new name to match the renamed STL.

- ALERT AHDC digitization now reads `/calibration/alert/ahdc/time_to_distance_wire` with ten coefficients
  per wire instead of the former global six-coefficient `time_to_distance` table.
- FT readout is disabled for `rgk_winter2018`, `rgf_spring2020`, `rgd_fall2023`, and `rgc_summer2022`.
- Custom DDVCS gcards must load the beamline `ddvcs` variation to include the Moller cone.
- Direct MuCAL generation now uses `mucal.pl` instead of `init_muCal.pl`.
