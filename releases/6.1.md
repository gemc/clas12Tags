# GEMC Release 6.1

This version includes:

- Expanded run-dependent geometry for BAND, RGK targets, magnets, HTCC, and micromegas.
- Updated ATOF and CTOF digitization, including run-dependent timing and hit-position corrections.
- Corrected ALERT helium materials.
- Reworked DDVCS flux detectors and added the missing MuRT gcard.
- Added deployment, binary-package, and GEMC2 reference-HIPO workflows.

Based on [Coatjava Release](https://github.com/JeffersonLab/coatjava/releases) 14.1.2.

<br/>

# Release notes

- Fixed SQLite run fallback selection by sorting run candidates before choosing the latest run less than
  or equal to `RUNNO`.
- Added run-dependent BAND presence transitions and SQLite/TEXT gcards using the `default` variation.
- Added RGK fall 2023 and spring 2024 targets and populated their run-dependent geometry and CAD rows.
- Updated ATOF timing digitization with fixed timing resolutions and run-dependent radiation-damage
  corrections read from the slope and intercept constants.
- Corrected CTOF hit-position-bin loading and application, including use of the hit's laboratory z
  coordinate.
- Corrected the ALERT helium target composition and increased the ATOF helium-gas density from 3 atm to
  4.5 atm.
- Reworked the DDVCS central, shield, and forward flux detectors as thin scoring planes and corrected the
  DDVCS digitization variation.

<br/>

## Documentation

- Documented the BMT and FMT z-position parameters and the shifts applied to match the CLAS12 configuration
  gcards.

<br/>

## Examples

- Added the missing MuRT gcard.
- Added dedicated BAND SQLite and TEXT gcards and renamed the BAND geometry, hit, and material variation
  files from `main` to `default`.
- Updated the DDVCS gcard to use the shared `fluxDets` geometry and the `rgd_fall2023_mc` digitization
  variation.

<br/>

## Tests

- Updated geometry comparisons to use run numbers appropriate to RGK, beamline, target, micromegas, and
  BAND configurations.
- Added workflows that build and publish multi-architecture container images and binary tarballs, then test
  the tarballs in minimal supported environments.
- Added a workflow that produces rolling GEMC2 reference HIPO files for GEMC3 histogram comparisons.
- Changed the development-versus-main geometry comparison workflow to manual dispatch only.

<br/>

## Compatibility notes

- BAND now uses the `default` variation instead of `main`. Custom BAND gcards that select `main` must be
  updated.
- CLAS12 magnet CAD rows are stored under `magnets_cad`, matching the supplied SQLite gcards.
- The `rgk_winter2023` comparison uses `RUNNO=19200`.
- `rgd_fall2023_Cu` and `rgd_fall2023_Sn` use the `rgd_fall2023_CuSn` target variation. Matching SQLite
  runs include `18347`, `18372`, `18560`, `18660`, `18874`, and `19061`.
- CTOF CAD in the 5.14 `rga_fall2018` geometry is missing the upstream light guides. Their presence in the
  SQLite geometry is a known 5.14 omission, not a 6.1 regression.

<br/>

## Detailed list of changes and fixes

- Applied CLAS12 gcard BMT and FMT shifts directly through micromegas parameters and corrected the RGD
  micromegas positions and dimensions.
- Corrected the RGK winter 2023 SQLite gcard so it uses its real run number instead of falling back to run
  11.
- Populated target CAD SQLite rows for RGA, RGB, RGD, RGE, RGF, and RGK run-dependent variations.
- Imported HTCC CAD definitions from gxml into SQLite while preserving their CLAS12-relative CAD paths.
- Stored magnet CAD definitions using the detector name expected by the SQLite gcards.
- Corrected the beamline CI run-to-variation mapping and added RGK runs to micromegas and target checks.
- Added ATOF slope and intercept tables and applied their run-dependent timing correction.
- Corrected ATOF and ALERT helium material definitions.
- Corrected CTOF binned hit-position calibration loading and response calculation.
- Added BAND SQLite rows for each detector-presence transition across the supported real-run-number ranges.
- Replaced the two original DDVCS flux volumes with central and forward polycones and twelve sector/layer
  shield scoring planes.
- Added automated deployment, binary-tarball validation, and rolling reference-HIPO generation.
- Disabled the scheduled development-versus-main comparison while retaining manual execution.
